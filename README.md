# .github

Community-health defaults for every repo under
[gmhoward9289-ops](https://github.com/gmhoward9289-ops).

GitHub reads `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`, the issue
templates and the pull request template from this repo for **any repo that does
not carry its own copy**. A repo-level file always wins, so a project with
specific build or test instructions keeps its own `CONTRIBUTING.md` and inherits
the rest from here.

This repo has to stay **public** for any of that to apply — the defaults in a
private `.github` repo silently apply to nothing.

| file | what it covers |
|---|---|
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | conduct, and the honest limits of reporting on a solo project |
| [CONTRIBUTING.md](CONTRIBUTING.md) | the fallback contributor guide; repo-level files override it |
| [SECURITY.md](SECURITY.md) | private disclosure to dev@swamplink.com, and what is in scope |
| [.github/ISSUE_TEMPLATE/](.github/ISSUE_TEMPLATE) | bug report, feature request, and the links shown beside them |
| [.github/PULL_REQUEST_TEMPLATE.md](.github/PULL_REQUEST_TEMPLATE.md) | the PR checklist |
